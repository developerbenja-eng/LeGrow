# Grow Tent Setup Guide

## Recommended First Setup: 3x3 Tent with Seascape Strawberries

### Why Start with Strawberries
- No dormancy needed (day-neutral = fruits year-round)
- No thorns
- Continuous harvest (not seasonal)
- First fruit in 8-12 weeks from bare root
- Forgiving (hard to kill)
- Self-renewing (runners = free plants)
- 3-4 lbs per plant per year
- Indoor can beat outdoor yields by 30%

### Environment Targets
| Parameter | Day | Night |
|-----------|-----|-------|
| Temperature | 68-75°F (20-24°C) | 50-54°F (10-12°C) |
| Humidity | 40-60% | 40-60% |
| Light | 300-350 PPFD | OFF (6-8 hrs dark) |
| Light schedule | 6:00 PM → 8:00 AM | 8:00 AM → 6:00 PM |
| Airflow | Light circulation | Exhaust on timer |

### Step-by-Step Setup
1. Assemble tent
2. Mount light at top (use rope ratchets for height adjustment)
3. Install inline fan + ducting (exhaust out top, intake at bottom)
4. Set up clip fan for air circulation
5. Place drip trays, then pots
6. Mix soil (70% Fox Farm + 30% perlite)
7. Soak bare root strawberries 1 hour in water
8. Plant one per pot, crown at soil level
9. Water thoroughly
10. Set light to 60% power, 14-16 hours
11. Mount ESP32 sensor system
12. Connect auto-watering system
13. Monitor and adjust

### Light Height Guide
| Growth Stage | Height Above Plants |
|-------------|-------------------|
| New transplants | 24-30 inches |
| Vegetative growth | 18-24 inches |
| Flowering/fruiting | 12-18 inches |

### Watering Guide
- Strawberries like consistent moisture but NOT waterlogged
- Water when top inch of soil is dry
- With auto-watering: trigger at 40% soil moisture, stop at 70%
- Use room-temperature water
- pH water to 5.8-6.2

### Timeline
| Week | What Happens |
|------|-------------|
| 0 | Order bare roots (March shipping season) |
| 1 | Arrive, soak, plant in tent |
| 2-4 | Vegetative growth, runners start |
| 6-8 | First flowers appear |
| 8-12 | First ripe strawberries |
| 12+ | Continuous harvest year-round |
| Month 6+ | Use runners to fill spots or start second tent |
